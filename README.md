# Praxisbesuche Mathematik

Planungsseite für die Praxisbesuche der Fachdidaktik Mathematik (PH Luzern).

Die Seite enthält **keine Daten**. Sie liest und schreibt nur in einem Ordner, den man auf dem eigenen
Rechner selbst auswählt (der mit OneDrive synchronisierte Teams-Ordner «Praxisbesuche»).
Ohne diesen Ordner zeigt sie nichts an. Funktioniert nur in Chrome oder Edge.

- `index.html` – die Seite
- `rundgang.html` – Rundgang mit erfundenen Beispieldaten
- `lesezeichen.txt`, `export-praktikumstool.js` – Lesezeichen, das die Mathe-Praktika aus dem Praktikumstool liest
